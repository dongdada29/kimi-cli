Browser automation tool that provides web page interaction capabilities. This tool allows you to navigate to URLs, take snapshots of pages, click elements, type text, and capture screenshots.

**Capabilities:**
- Navigate to URLs
- Get page snapshots (accessibility tree)
- Click on page elements
- Type text into input fields
- Take screenshots
- Hover over elements
- Select dropdown options
- Wait for content to appear/disappear

**Note:** This tool uses Chrome DevTools Protocol via MCP. It requires a Chrome/Chromium browser to be available on the system.
